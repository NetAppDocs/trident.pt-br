= Problemas conhecidos
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Problemas conhecidos identificam problemas que podem impedi-lo de usar esta versão do produto com sucesso.

Os seguintes problemas conhecidos afetam a versão atual:



[[volumes-remain-attached-after-upgrading-from-trident-22-10-or-earlier]]
== Os volumes permanecem anexados após a atualização do Trident 22.10 ou anterior

Este problema afeta clientes que atualizam diretamente do Trident 22.10 ou anterior para o Trident 26.10 com volumes anexados. Atualizações do Trident 23.01 ou posterior não são afetadas.

Após a atualização, os volumes afetados podem não se desanexar. Os pods que usam volumes ReadWriteOnce (RWO) não podem ser movidos para outro nó e podem relatar um erro de anexação múltipla. A exclusão do PersistentVolume (PV) também pode travar.

Para contornar esse problema, no nó que possui o anexo de volume obsoleto, exclua o  `volumePublishInfo.json`arquivo remanescente do  `globalmount`diretório desse volume.



[[volumesnapshots-not-reaching-readytouse-state]]
== VolumeSnapshots não atingindo o estado ReadyToUse

[WARNING]
====
Existe um problema conhecido com o `csi-snapshotter` sidecar. Em todas as versões do Kubernetes, VolumeGroupSnapshots `v1beta1` impede que VolumeSnapshots alcancem o `ReadyToUse` estado.

====
Duas soluções alternativas estão disponíveis:

. Exclua os CRDs VolumeGroupSnapshots para desativar VolumeGroupSnapshots e, em seguida, reinstale Trident.
. Instale VolumeGroupSnapshots `v1beta2` e  `snapshot-controller` versão 8.4.0 ou posterior e, em seguida, reinstale Trident. VolumeGroupSnapshots não funciona em versões do Kubernetes anteriores à v1.34.




[[restoring-restic-backups-of-large-files-can-fail]]
== Restaurar backups Restic de arquivos grandes pode falhar

Ao restaurar arquivos de 30 GB ou maiores a partir de um backup do Amazon S3 feito com o Restic, a operação de restauração pode falhar. Como solução alternativa, faça backup dos dados usando o Kopia como gerenciador de dados (o Kopia é o gerenciador de dados padrão para backups). Consulte https://docs.netapp.com/us-en/trident/trident-protect/trident-protect-protect-apps.html["Proteja aplicativos usando o Trident Protect."^] para obter instruções.
